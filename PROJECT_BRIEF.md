Build a modern web application called ProjectForge.

ProjectForge is a professional developer project portfolio and progress tracking platform.

The application should help users manage, organize, track, and showcase their personal or professional projects through a clean dashboard interface.

Core Features:

1. Project Dashboard
- Display all projects in a responsive card-based layout.
- Show project title, description, status, progress percentage, deadline, and technology stack.
- Allow searching, filtering, and sorting projects.

2. Project Management
- Create new projects.
- Edit existing projects.
- Delete projects.
- Add project descriptions and notes.
- Set deadlines.
- Assign project status:
  - Planning
  - In Progress
  - Testing
  - Completed

3. Milestone Tracking
- Create milestones for each project.
- Mark milestones as completed.
- Automatically update project progress based on milestone completion.

4. Analytics Dashboard
- Total projects.
- Completed projects.
- Active projects.
- Upcoming deadlines.
- Overall completion rate.
- Visual progress indicators and charts.

5. Technology Tracking
- Allow users to add technologies used in each project.
- Show the most frequently used technologies.
- Display technology badges.

6. Project Showcase
- Dedicated section for completed projects.
- Display project highlights.
- Allow adding GitHub links and live deployment links.
- Professional portfolio-style presentation.

7. Notes and Documentation
- Each project should have a notes section.
- Users can store ideas, requirements, and implementation notes.

8. Local Persistence
- Save all data using local storage.
- Automatically restore data when reopening the application.

9. User Experience
- Modern premium SaaS-inspired design.
- Professional typography.
- Responsive for desktop and mobile.
- Smooth animations and transitions.
- Clean dashboard layout.
- Dark mode support.

10. Advanced Features
- Export project data.
- Project completion insights.
- Deadline reminders.
- Progress history tracking.

Important Product Principles:
- Prioritize usability over feature quantity.
- Make the application feel like a premium productivity product.
- Focus on clarity, organization, and professional presentation.
- Design should be impressive enough to showcase to mentors, recruiters, or clients.
- Use your own judgment to improve the application where appropriate.
- Add thoughtful enhancements if they improve the overall user experience.
- Avoid unnecessary complexity while maintaining a polished and professional feel.

The final application should feel like a real software product rather than a beginner project.
